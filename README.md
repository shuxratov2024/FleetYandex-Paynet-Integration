# Yandex Fleet & Paynet.uz Integration 

Welcome to the **FleetYandex-Paynet-Integration** repository! 

This project connects **Yandex Fleet** (taxi/transport management system) with the **PAYNET.UZ** payment system. It is entirely built with **100% JavaScript**.

## 📌 About the Project
The main goal of this project is to automate and simplify the balance top-up process for Yandex Taxi drivers. Originally developed for the "PARK PEGAS" taxi fleet, this integration securely accepts payments via Paynet.uz and instantly updates the driver's balance in the Yandex Fleet system.

## 💻 Technologies Used
* **100% JavaScript (Node.js)**
* Yandex Fleet API
* Paynet API
* REST API Architecture

## ⚙️ How It Works
1. Identifies the specific driver within the Yandex Fleet system.
2. Securely processes the top-up transaction through PAYNET.UZ.
3. Automatically updates the driver's working balance in real-time.
